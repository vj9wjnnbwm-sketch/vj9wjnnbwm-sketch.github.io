# vj9wjnnbwm-sketch.github.io

Personal homepage of Kim Ihyeon (김이현), a student researcher in computational biology at Haeryong High School.

Live site: https://vj9wjnnbwm-sketch.github.io

## About

A single-page site (`index.html`, no build step) covering:

- Research on protein subcellular localization using ESM-2 embeddings and semi-supervised learning
- Recognition and awards
- Contact links

The page supports English and Korean (EN/KO toggle) and follows the system light/dark theme.

## Local preview

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.
