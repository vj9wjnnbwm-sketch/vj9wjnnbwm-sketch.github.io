# 은하 형태 비지도 학습 탐구 로드맵

이 문서는 Claude Code가 처음부터 끝까지 따라가며 프로젝트를 만들기 위한 작업 지시서다.
각 Phase를 순서대로 진행하고, Phase가 끝날 때마다 결과를 짧게 보고한 뒤 다음으로 넘어간다.

## 프로젝트 목표

라벨 없이 은하 사진만 가지고 컴퓨터가 스스로 은하를 무리 지을 수 있는지 확인한다.
그 결과를 허블 분류(타원은하, 나선은하, 불규칙은하)와 비교해서
"사람이 정한 기준과 기계가 찾은 기준이 얼마나 같고 어떻게 다른가"를 탐구한다.

핵심 원칙은 정답 라벨을 학습에 절대 쓰지 않는 것이다. 라벨은 마지막 평가 단계에서만 꺼낸다.

## 폴더 구조

```
galaxy-unsupervised/
├── ROADMAP.md
├── requirements.txt
├── data/
│   ├── raw/            # 원본 이미지 (png)
│   └── labels.csv      # 평가 전용 정답표, 학습 코드에서 읽지 않음
├── features/           # 추출한 특징 벡터 (.npy)
├── outputs/
│   ├── figures/        # 보고서용 그림
│   └── tables/         # 보고서용 표
└── src/
    ├── 01_download.py
    ├── 02_preprocess.py
    ├── 03_extract_features.py
    ├── 04_cluster.py
    ├── 05_visualize.py
    ├── 06_evaluate.py
    └── 07_experiments.py
```

## Phase 0 환경 준비

- Python 3.10 이상 가상환경을 만든다.
- requirements.txt에 아래를 넣고 설치한다.
  - torch, torchvision
  - scikit-learn, numpy, pandas
  - matplotlib, pillow, h5py, tqdm
  - umap-learn (설치가 안 되면 t-SNE만 사용)
- GPU가 없어도 돌아가게 작성한다. CPU 기준으로 이미지 3000장 특징 추출이 10분 안쪽이면 충분하다.

완료 기준은 `python -c "import torch, sklearn"`이 오류 없이 끝나는 것.

## Phase 1 데이터 확보

기본 데이터셋은 Galaxy10 DECaLS(약 1만 8천 장, 256x256 컬러, 10개 세부 클래스)를 쓴다.
astroNN 문서에 안내된 공식 다운로드 링크를 확인해서 받는다. 파일이 2GB 이상이므로 받기 전에 사용자에게 용량을 알리고 확인을 받는다.

세부 클래스를 허블 분류 3종으로 묶는 규칙은 다음과 같다.

| Galaxy10 번호 | 원래 이름 | 탐구용 분류 |
|---|---|---|
| 2, 3, 4 | Round Smooth, In-between Round Smooth, Cigar Shaped Smooth | 타원은하 |
| 5, 6, 7, 8, 9 | Barred Spiral, Tight Spiral, Loose Spiral, Edge-on 두 종류 | 나선은하 |
| 0, 1 | Disturbed, Merging | 불규칙은하 |

- 세 분류가 각 1000장씩 되도록 무작위로 뽑는다 (random seed 42 고정).
- 이미지는 data/raw/에 png로 저장하고, 파일명과 원래 클래스, 탐구용 분류를 data/labels.csv에 기록한다.
- 다운로드가 막히는 환경이면 사용자가 직접 모은 사진 폴더를 data/raw/에 넣는 방식으로 대체한다. 이 경우 labels.csv는 사용자가 아는 범위에서만 채운다.

완료 기준은 data/raw/에 3000장, labels.csv에 3000행이 있는 것.

## Phase 2 전처리

- 은하가 가운데 있으므로 중앙을 잘라(center crop) 배경 비중을 줄인 뒤 224x224로 맞춘다.
- ImageNet 평균과 표준편차로 정규화한다.
- 전처리 전후 비교 그림 1장을 outputs/figures/preprocess_example.png로 저장한다.

## Phase 3 특징 추출

라벨 없이 사진을 숫자로 바꾸는 단계다.

- 주 방법은 ImageNet으로 사전학습된 ResNet50의 마지막 분류층을 떼고, 2048차원 벡터를 뽑는 것이다.
- 은하는 방향이 의미 없으므로 회전 불변성을 주기 위해 0도, 90도, 180도, 270도 회전본 4장의 벡터를 평균 낸 버전도 함께 만든다.
- 비교용 기본 방법으로 사람이 해석할 수 있는 간단한 특징도 계산한다.
  - 타원율 (밝은 영역의 장축 대 단축 비)
  - 집중도 (중심부 밝기 비율)
  - 비대칭도 (180도 회전 후 차이)
  - 평균 색 (R, G, B)
- 결과는 features/resnet.npy, features/resnet_rot.npy, features/handcrafted.npy로 저장한다.

## Phase 4 군집화

- 특징을 표준화하고 PCA로 50차원까지 줄인다.
- K-평균 군집화를 k=3으로 실행한다 (n_init=10, random_state=42).
- k를 2부터 10까지 바꿔 가며 엘보 곡선(관성)과 실루엣 점수를 그린다. 컴퓨터 입장에서 자연스러운 무리 수가 3이 맞는지 확인하기 위함이다.
- 군집 결과는 outputs/tables/clusters.csv에 파일명, 군집 번호 형태로 저장한다.

## Phase 5 시각화

- t-SNE (가능하면 UMAP도)로 2차원 지도를 만들어 두 장을 나란히 그린다.
  - 왼쪽은 군집 번호로 색칠
  - 오른쪽은 정답 분류로 색칠
- 군집별로 대표 사진 16장씩을 격자로 보여 주는 그림을 만든다. 군집 중심에 가까운 사진 8장, 먼 사진 8장으로 나눈다.
- 엘보 곡선과 실루엣 점수 그래프를 저장한다.
- 그림 안의 글자는 한글이 깨지지 않도록 한글 폰트를 설정한다. 폰트가 없으면 영어로 표기한다.

## Phase 6 평가

여기서 처음으로 labels.csv를 읽는다.

- 군집 번호와 정답 분류의 교차표를 만든다.
- 각 군집에 가장 많이 들어 있는 정답 분류를 그 군집의 이름으로 붙이고 순도(purity)를 계산한다.
- ARI(조정 랜드 지수)와 NMI(정규화 상호정보량)를 계산한다.
- 잘못 묶인 사진들을 모아 보고, 무엇 때문에 헷갈렸는지 추측할 수 있게 사진 격자를 저장한다.
- 결과 표는 outputs/tables/에 csv와 보기 좋은 markdown 두 형식으로 저장한다.

## Phase 7 비교 실험

아래 조합을 같은 방식으로 돌려 하나의 표로 정리한다.

| 실험 | 특징 | 비고 |
|---|---|---|
| A | handcrafted | 사람이 정한 기준 |
| B | resnet | 기본 딥러닝 특징 |
| C | resnet_rot | 회전 평균 |
| D | resnet, 흑백 입력 | 색 정보를 뺐을 때 |

각 실험마다 순도, ARI, NMI를 기록한다. 어떤 조건에서 허블 분류에 가장 가까워지는지,
반대로 색이나 밝기 같은 모양 외의 기준으로 묶이는 경향이 있는지 확인한다.

## Phase 8 보고서 자료 정리

outputs/REPORT_NOTES.md를 만들어 학생이 보고서에 옮겨 적기 쉽게 정리한다.

- 보고서 1번 칸 대응 정보로 군집별 사진 수, 군집에 붙인 이름, 순도
- 보고서 2번 칸에 넣을 그림 추천 (t-SNE 비교 그림, 군집별 사진 격자)
- 지도 학습(티처블 머신)과의 차이를 설명하는 문단 초안
- 기계가 모양 대신 다른 기준으로 묶은 사례와 그 이유 추측
- 탐구의 한계 (데이터 수, 사전학습 모델이 일상 사진으로 학습됨, 세부 클래스 묶기 규칙의 임의성 등)

문체는 고등학생 탐구 보고서 수준의 평이한 한국어로 쓴다.

## Claude Code 작업 규칙

- Phase마다 스크립트 하나씩 만들고, 각 스크립트는 단독으로 다시 실행해도 같은 결과가 나오게 한다.
- random seed는 모든 곳에서 42로 고정한다.
- 큰 파일 다운로드, 패키지 대량 설치 전에는 사용자에게 먼저 묻는다.
- 오류가 나면 원인을 한두 줄로 설명하고 고친 뒤 다시 실행한다.
- 모든 Phase가 끝나면 outputs/ 안의 파일 목록과 핵심 수치 3개(순도, ARI, NMI)를 요약해서 보고한다.
